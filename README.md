# 📡 Estudos em Redes de Computadores

Repositório com anotações, resumos e materiais de estudo sobre fundamentos de redes de computadores — do básico (topologias, modelo OSI) até tópicos mais avançados (VLAN, roteamento dinâmico, segurança e cloud).

## 🎯 Objetivo

Organizar e consolidar o aprendizado sobre redes, servindo como guia de referência rápida e material de revisão para estudos.
