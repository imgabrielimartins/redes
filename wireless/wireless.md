# 📶 Wireless

Wireless significa comunicação sem fio, normalmente usando ondas de rádio para conectar dispositivos à rede.

Um exemplo simples:

```
📱 Celular   )))
💻 Notebook  ))) → 📡 Access Point → 🌐 Rede/Internet
📺 TV        )))
```

---

## 📡 2.4 GHz

É uma frequência bastante utilizada em redes Wi-Fi.

**Características:**

- 📶 Maior alcance
- 🧱 Atravessa paredes melhor
- 🐌 Geralmente oferece menos velocidade que 5 GHz
- 🚦 Possui mais interferência e congestionamento

É uma boa opção quando o dispositivo está mais longe do roteador.

🧠 **Para lembrar:** 2.4 GHz = mais alcance, menos velocidade

---

## 🚀 5 GHz

Oferece velocidades maiores que 2.4 GHz e normalmente sofre menos interferência.

**Características:**

- 🚀 Maior velocidade
- 📶 Menor alcance que 2.4 GHz
- 🧱 Tem mais dificuldade para atravessar paredes
- 📡 Geralmente possui mais canais disponíveis

É uma boa opção quando você está mais perto do roteador.

🧠 **Para lembrar:** 5 GHz = mais velocidade, menos alcance

---

## ⚡ 6 GHz

A faixa de 6 GHz é utilizada pelo Wi-Fi 6E e também por gerações posteriores de Wi-Fi que operam nessa faixa.

**Características:**

- 🚀 Alta velocidade
- 📡 Mais espectro disponível
- 📶 Menor alcance que 2.4 GHz
- 🧱 Maior dificuldade para atravessar obstáculos
- 🔀 Menos congestionamento em ambientes compatíveis

Para utilizar 6 GHz, o roteador/access point e o dispositivo precisam ser compatíveis.

🧠 **Para lembrar:** 6 GHz = mais espectro e menos congestionamento, mas menor alcance

---

## Por que existe essa troca entre alcance e velocidade?

Isso não é coincidência: quanto maior a frequência de uma onda de rádio, mais dados ela consegue transportar por segundo — mas, em compensação, ela perde energia mais rápido ao atravessar o ar e obstáculos como paredes.

```
Frequência baixa (2.4 GHz)   →  onda "mais larga"  →  vai mais longe, carrega menos dados
Frequência alta (6 GHz)      →  onda "mais fina"    →  vai menos longe, carrega mais dados
```

É por isso que roteadores modernos costumam transmitir nas três faixas ao mesmo tempo, deixando o dispositivo escolher (ou escolhendo automaticamente) a melhor conforme a distância e o congestionamento do momento.

## 🏷️ SSID

**SSID** (*Service Set Identifier*) é o nome da rede Wi-Fi.

**Por exemplo, redes Wi-Fi:**

- Casa_Gabi
- WiFi_Empresa
- Internet_5G

Quando você abre a lista de redes Wi-Fi no celular, os nomes que aparecem são os SSIDs.

📌 O SSID não é a senha.

```
SSID:  Casa_Gabi
Senha: ********
```

---

## 🔐 WPA2

**WPA2** (*Wi-Fi Protected Access 2*) é um padrão de segurança para redes Wi-Fi.

Ele protege a comunicação entre o dispositivo e o Access Point usando criptografia.

É muito comum encontrar **WPA2-Personal** (WPA2-PSK).

Em uma rede doméstica:

```
📱 Celular
    ↓
Senha Wi-Fi
    ↓
📡 Access Point
    ↓
🔐 WPA2
```

---

## 🔒 WPA3

WPA3 é uma geração mais nova de segurança Wi-Fi.

Ele oferece melhorias de segurança em relação ao WPA2 e utiliza mecanismos mais modernos de autenticação.

Uma vantagem importante é o **SAE** (*Simultaneous Authentication of Equals*) no modo pessoal, que melhora a proteção contra tentativas de descobrir a senha.

🧠 **Para lembrar:**
- WPA2 = segurança Wi-Fi tradicional e ainda muito comum
- WPA3 = segurança Wi-Fi mais moderna
