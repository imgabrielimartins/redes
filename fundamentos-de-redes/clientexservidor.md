# Cliente x Servidor

O modelo Cliente-Servidor é uma arquitetura de rede em que um computador (cliente) solicita um serviço ou recurso, e outro computador (servidor) fornece esse serviço.

## Cliente

É o dispositivo ou programa que faz uma solicitação ao servidor.

Exemplos:

- Navegador (Chrome, Edge, Firefox)
- Aplicativo do banco
- WhatsApp
- Computador de um funcionário

## Servidor

É o computador ou programa que recebe as solicitações, processa as informações e envia uma resposta ao cliente.

Exemplos:

- Servidor de arquivos
- Servidor web
- Servidor de banco de dados
- Servidor de e-mail

## Como funciona?

1. O cliente envia uma requisição.
2. O servidor recebe e processa a requisição.
3. O servidor envia a resposta.
4. O cliente exibe o resultado ao usuário.

### Exemplo:

- Você abre o navegador.
- Digita [www.google.com](https://www.google.com).
- O navegador (cliente) envia uma solicitação ao servidor do Google.
- O servidor responde com a página.
- O navegador mostra o site na tela.

## Comparação

| Cliente | Servidor |
|---------|----------|
| Solicita serviços | Fornece serviços |
| Inicia a comunicação | Aguarda solicitações |
| Exemplo: navegador, celular, computador | Exemplo: servidor web, servidor de banco de dados, servidor de arquivos |

## Exemplos do dia a dia

- **Netflix**: sua TV ou celular é o cliente; os servidores da Netflix enviam os vídeos.
- **WhatsApp**: seu aplicativo é o cliente; os servidores do WhatsApp encaminham as mensagens.
- **Sistema da empresa**: o computador do funcionário é o cliente; o servidor armazena os dados do sistema.

## Resumo para memorizar

```
Cliente  → Faz a solicitação.
Servidor → Processa a solicitação e responde.
```
